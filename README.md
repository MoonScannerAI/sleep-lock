# Sleep Lock

At bedtime, tap Arm. After N hours (1-12, chosen each night) every app except the ones you allowed (Phone, Messages, Maps) is shielded. Unlocking requires solving a random 4-digit x 4-digit multiplication inside the app. Cancel is possible only while armed and before the lock starts.

Built with SwiftUI, FamilyControls, ManagedSettings and DeviceActivity (iOS 16+). The Xcode project is generated by XcodeGen and built on GitHub Actions, so no Mac is needed.

## One-time setup (Windows, paid Apple Developer account)

1. Create a **public** GitHub repo and push this folder to its `main` branch.
2. App Store Connect > Users and Access > Integrations > App Store Connect API: generate a key with the **Admin** role (needed for cloud-managed signing certificates). Note the Key ID and Issuer ID and download the `.p8`. Find your Team ID at developer.apple.com > Membership.
3. Repo Settings > Secrets and variables > Actions: add secrets `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8` (full file contents, including BEGIN/END lines) and `APPLE_TEAM_ID`. Optionally add a repository variable `BUNDLE_PREFIX` (must be unique to you, e.g. `com.yourname`; default `com.andyli`).
4. Register your iPhone UDID at developer.apple.com > Devices. Get the UDID by connecting the iPhone to the Windows "Apple Devices" app and clicking the serial number area until the UDID shows, or via Sideloadly.
5. Repo Settings > Pages > Source: **GitHub Actions**.
6. Run the workflow (Actions > Build > Run workflow, `export_method=development`). When done, open `https://<user>.github.io/<repo>/` in Safari on the iPhone and tap Install. Then Settings > Privacy & Security > Developer Mode > On (the phone restarts).
7. If signing fails on capabilities: at developer.apple.com > Identifiers, manually enable Family Controls (Development) and App Groups on all four App IDs, create the app group `group.<prefix>.sleeplock`, assign it to all four, then re-run.
8. For TestFlight later: request the Family Controls distribution entitlement at https://developer.apple.com/contact/request/family-controls-distribution for all four bundle IDs (`<prefix>.sleeplock`, `.ActivityMonitor`, `.ShieldConfig`, `.ShieldAction`). Once approved, run the workflow with `export_method=app-store`.

## How to use

1. Open the app, authorize Screen Time and notifications.
2. In "Choose allowed apps" select Phone, Messages and Maps, then tap Done.
3. At bedtime pick the number of hours and tap Arm.
4. You can Cancel while the countdown runs. Once the lock starts there is no cancel.
5. To unlock, open Sleep Lock (the shield's button sends a notification you can tap) and solve the multiplication. A wrong answer gives a new problem.

Testing: long-press the "Sleep Lock" title on the Arm screen to arm with a 15 minute delay (the DeviceActivity minimum). The Log screen (top-right icon) shows what happened.

## Known loopholes

- Settings > Screen Time can revoke this app's access (with `.individual` authorization).
- Changing the system date/time may affect the schedule.
- The Settings app cannot be blocked.
